♔ ChessLab v{{ version }}

Osobní šachová laboratoř — lokální Python app pro analýzu partií, hraní proti enginu a engine arenu. Backend FastAPI, frontend vanilla JS + chessboard.js.

Features

  • PGN viewer — načtení partie, navigace tahů.
  • API dokumentace — OpenAPI/Swagger UI pro testování endpointů.

Brzy přijde

  • Stockfish analýza (eval bar, graf hodnocení)
  • Hraní proti UCI enginu
  • Engine arena (engine vs. engine, ELO tabulka)
  • Import partií z Lichess API

Repo: github.com/mrklas69/ChessLab
